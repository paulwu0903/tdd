# Rule 1 - NFR 量測卡紅燈已達標時，綠燈只記錄量測值 [MUST]
- NFR 量測卡在紅燈時已達標，綠燈不改程式，重新執行該卡的測試並記錄量測值即完成。
- 紅燈未達標時，綠燈依一般流程寫出讓量測達標的最少實作。

## Good Example
- 紅燈已達標，綠燈只重跑量測並記錄。

```
T043 `/tdd 綠燈` SL-025（紅燈時 1.4 秒，已達標）
執行：npx playwright test chat-nfr.spec.ts -g SL-025 → passed，最大延遲 1.5 秒
處理：不改 frontend/lib/use-messages.ts 與 chat.tsx
判定：記錄 1.5 秒，綠燈完成
```

## Bad Example
- 紅燈已達標，綠燈仍去調整輪詢間隔，加入卡片沒有要求的改動。

```
T043 `/tdd 綠燈` SL-025（紅燈時 1.4 秒，已達標）
處理：把 use-messages.ts 的輪詢間隔由 1000ms 改為 300ms
判定：綠燈完成
```
