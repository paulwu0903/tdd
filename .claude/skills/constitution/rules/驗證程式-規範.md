# Rule 1 - 介面固定為 --file 與 exit 0／1／2 [MUST]
- 執行方式固定為 `uv run checks/<名稱>.py --file <產出物路徑>`，一次檢查一個檔案。
- 違反位置寫 stdout，一行一個。
- exit code 固定為：
    - `0`：通過
    - `1`：違反
    - `2`：不支援這種格式的檔案；該 Rule 對這個檔案改由逐條自檢判定

## Good Example
- 只接 `--file`；不是 openapi / asyncapi 時回傳 2。

```python
parser.add_argument("--file", required=True, type=Path)
if args.file.suffix not in (".yaml", ".yml"):
    return 2
for v in violations:
    print(v)
return 1 if violations else 0
```

## Bad Example
- 一次掃整個目錄，有違反仍回傳 0，affected.py 無法判定結果。

```python
parser.add_argument("--dir")
print(f"{len(violations)} violations found")
return 0
```
