# Rule 1 - JSON 欄位名稱一律 lowerCamelCase [MUST]
- 驗證：script checks/field_camel_case.py
- request、response 與 parameter 的每個欄位名稱都是 lowerCamelCase（`^[a-z][a-zA-Z0-9]*$`）。

## Good Example
- 欄位皆為 lowerCamelCase。

```yaml
properties:
  endedAt: { type: string, format: date-time }
  winCount: { type: integer, minimum: 0 }
```

## Bad Example
- 資料庫的 snake_case 直接漏到 API。

```yaml
properties:
  ended_at: { type: string, format: date-time }
  win_count: { type: integer, minimum: 0 }
```

# Rule 2 - 錯誤碼為 UPPER_SNAKE_CASE [MUST]
- 驗證：script checks/error_code_format.py
- 錯誤碼一律為 UPPER_SNAKE_CASE（`^[A-Z][A-Z0-9_]*$`）。

## Good Example
- 錯誤碼皆為大寫底線。

```yaml
enum: [ROOM_FULL, ROOM_CLOSED, INTERNAL]
```

## Bad Example
- 大小寫混用。

```yaml
enum: [roomFull, room_closed, INTERNAL]
```
