# SOP

## Phase 1 -- 確認目標
1. READ 讀取目標 skill 內容，確認要新增、修改或重寫的 SOP 範圍。

## Phase 2 -- 整理流程
1. THINK 整理出最少必要的 phase 與 step。
2. READ 讀取 `rules/SOP-設計原則.md` 與 `rules/SOP-格式規範.md`，依原則收斂步驟與載入時機，並依規範排版。

## Phase 3 -- 撰寫並回檢
1. WRITE 寫入目標 skill 的 SOP section。
2. READ 回頭檢查結果是否符合規範；若不符合，立即修正。
