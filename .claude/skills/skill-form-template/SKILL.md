# SOP

## Phase 1 -- 確認目標
1. READ 讀取目標 skill 的 SKILL.md 與既有 templates/，確認要新增、修改或重寫的樣板名稱與格式。

## Phase 2 -- 整理樣板
1. THINK 整理出骨架的最小固定結構，並定出哪些位置是填位符號。
2. READ 讀取 `rules/TemplateFile-格式規範.md`，依規範定出骨架與範例的寫法。

## Phase 3 -- 撰寫並回檢
1. WRITE 依規範寫入目標 skill 的 `templates/<名字>.<格式>` 與 `templates/<名字>.example.<格式>`。
2. READ 回頭檢查骨架與範例是否符合規範；若不符合，立即修正。
