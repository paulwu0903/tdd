# Rule 1 - Edge Cases 逐類掃描 [SHOULD]
- 整理 Edge Cases 時，逐一檢查下列類別，適用者各寫一條，寫明情境與預期處理：

| 類別 | 例 |
|---|---|
| 缺資料 | 照片沒有拍攝日期 |
| 重複 | 同一張照片重複匯入 |
| 刪除連帶 | 刪除仍含照片的相簿 |
| 極端規模 | 單一相簿 5,000 張照片 |
| 無效輸入 | 不支援的格式或損毀檔案 |
| 中斷 | 上傳途中網路中斷 |
| 並行 | 多個瀏覽器分頁同時操作 |
| 混合格式 | 直式與橫式照片混合 |

## Good Example
- 「中斷」類別寫出情境與預期處理，處理以承接它的 FR / NFR 編號引用。

```
- 照片上傳途中網路中斷或後端停止：依 NFR-009 保留已完整寫入的照片；依 FR-029 列出未成功的檔案供使用者重新上傳，未完成的檔案不出現在任何相簿。
```

## Bad Example
- 只寫情境，沒有預期處理，無法轉成測試。

```
- 上傳途中網路中斷。
```
