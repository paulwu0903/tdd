# Rule 1 - Success Criteria 帶數值門檻 [MUST]
- 每條 Success Criteria 都要有數值門檻（時間、比例、數量、寬度）。

## Good Example
- 時間與成功率都是具體門檻。

```
- **SC-001**: 新使用者在沒有說明文件的情況下，MUST 能在 3 分鐘內完成「匯入照片 → 建立相簿 → 加入照片 → 開啟相簿預覽」的完整流程，首次嘗試成功率 ≥ 90%。
```

## Bad Example
- 沒有任何數值門檻，無法判定是否達成。

```
- **SC-001**: 系統架構良好，使用者滿意。
```

# Rule 2 - 目標相同的 NFR 與 Success Criteria 互相對應 [SHOULD]
- NFR 與某條 Success Criteria 約束同一個目標時，在 NFR 末尾註明「對應 SC-xxx」。

## Good Example
- NFR-001 與 SC-002 是同一個效能目標，NFR 註明對應。

```
- **NFR-001**（適用：US1、US2、US3）: … 開啟含 500 張照片的相簿 MUST 在 2 秒內顯示首屏縮圖（對應 SC-002）。
```

## Bad Example
- 兩條寫著同一個門檻卻沒有連結，之後修改其中一條時另一條會跟不上。

```
- **NFR-001**（適用：US1、US2、US3）: … 開啟含 500 張照片的相簿 MUST 在 2 秒內顯示首屏縮圖。
- **SC-002**: … 開啟含 500 張照片的相簿 MUST 在 2 秒內顯示首屏縮圖。
```

# Rule 3 - 專屬某個 User Story 的 SC 門檻要有 NFR 承接 [MUST]
- 定 Success Criteria 時，若某條門檻只屬於某個 User Story，且該 User Story 還沒有需求承接它，就把它補成該 User Story 的 NFR，並註明對應。

## Good Example
- 匯出時限只屬於 US6，補成 US6 的 NFR。

```
- **SC-008**: … 1,000 張、總量 5 GB 以內的資料 MUST 在 5 分鐘內完成匯出且介面維持可操作。
- **NFR-031**（效能）: 1,000 張、總量 5 GB 以內的資料 MUST 在 5 分鐘內完成匯出，過程中介面 MUST 維持可操作（對應 SC-008）。
```

## Bad Example
- 匯出時限只寫在 SC，US6 底下沒有任何需求能被測試驗證這個門檻。

```
- **SC-008**: … 1,000 張、總量 5 GB 以內的資料 MUST 在 5 分鐘內完成匯出。
（US6 無對應 NFR）
```

# Rule 4 - Success Criteria 不含技術名詞 [MUST]
- Success Criteria 只寫使用者或業務看得到的成果，不出現語言、框架、資料庫、API、快取等技術名詞。
- 需要技術層的門檻時，寫成 NFR，再以「對應 SC-xxx」連回使用者面的 Success Criteria。

## Good Example
- 以使用者看到的結果衡量，技術層的延遲門檻留在 NFR。

```
- **SC-002**: 含 1,000 張照片、50 個相簿的資料量下，主頁面 MUST 在 2 秒內完成可互動呈現；開啟含 500 張照片的相簿 MUST 在 2 秒內顯示首屏縮圖。
```

## Bad Example
- 衡量的是系統內部元件，換了技術就失去意義，使用者也無從感受。

```
- **SC-002**: 後端 API p95 延遲 MUST ≤ 200 ms，資料庫快取命中率 MUST ≥ 80%。
```

# Rule 5 - Success Criteria 涵蓋使用者完成任務的成果 [SHOULD]
- 除了效能與容量，至少一條 Success Criteria 衡量使用者能否順利完成任務，例如完成時間、首次成功率、完成率或出錯後自行恢復的比例。
- 這類成果同樣以數值門檻表達。

## Good Example
- 以新使用者完成核心流程的時間與首次成功率衡量。

```
- **SC-001**: 新使用者在沒有說明文件的情況下，MUST 能在 3 分鐘內完成「匯入照片 → 建立相簿 → 加入照片 → 開啟相簿預覽」的完整流程，首次嘗試成功率 ≥ 90%。
```

## Bad Example
- 全部只衡量系統速度，看不出使用者是否真的會用。

```
- **SC-001**: 主頁面 MUST 在 2 秒內可互動。
- **SC-002**: 拖放操作 MUST 在 200 毫秒內反映新順序。
```
